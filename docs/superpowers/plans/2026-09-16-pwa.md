# Points Are Bad PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Points Are Bad installable and resilient on mobile and desktop without caching private/API data or changing live football behavior.

**Architecture:** `vite-plugin-pwa` generates the manifest and Workbox service worker, precaching only the compiled shell and public static assets while forcing `/api/**` through `NetworkOnly`. A focused React status component owns connectivity and update UI; the existing boot error path provides the full-page offline recovery state.

**Tech Stack:** React 19, Vite 7, `vite-plugin-pwa`, Workbox, Node test runner, CSS

**Spec:** `docs/superpowers/specs/2026-09-16-pwa-design.md`

## Global Constraints

- Installed launches start at `/dashboard`, remain scoped to `/`, use `display: standalone`, and allow any orientation.
- API, authentication, predictions, groups, standings, and live-score responses must never be cached or queued.
- Keep live-score polling and ordinary browser loading behavior unchanged.
- Preserve the existing early theme bootstrap and `public/ios.png` Apple touch icon.
- Provide 192px, 512px, and maskable 512px PNG icons from current PAB artwork.
- Updates require an explicit `Update` action; `Later` dismisses the prompt for the current page session.
